📧 Microsoft Outlook

Microsoft Outlook est bien plus qu'une boîte courriel : c'est l'outil central de gestion du temps et des communications formelles dans la majorité des entreprises utilisant Microsoft 365.

Le calendrier Outlook​

Planifier une réunion​

Une invitation de réunion Outlook bien construite contient :

  • Un titre clair (ex. : « Revue de sprint — Équipe Web » plutôt que « Meeting »)
  • Une description avec l'ordre du jour ou un lien vers le document pertinent
  • Les bons participants — seulement les personnes concernées
  • Le bon fuseau horaire, surtout en contexte d'équipe distribuée
  • Un lien de réunion Teams intégré automatiquement
astuce

Outlook affiche automatiquement les plages « Occupé » de vos invités quand vous planifiez une réunion (fonction Assistant Planification). Utilisez-la pour éviter les allers-retours de courriels à essayer de trouver un moment commun.

Catégories et couleurs​

Vous pouvez catégoriser vos rendez-vous par couleur (ex. : rouge = urgent, bleu = développement, vert = formation) pour visualiser rapidement votre semaine.

Le time blocking dans Outlook​

Comme vu dans la section sur la planification personnelle, vous pouvez réserver des blocs dans votre propre calendrier pour du travail concentré (ex. : « Focus — programmation »). Cela :

  • Rend votre disponibilité réelle visible à vos collègues
  • Réduit les interruptions pendant vos périodes de travail profond

La gestion des courriels​

La règle des 2 minutes​

Si un courriel peut être traité (répondu, classé, supprimé) en moins de 2 minutes, faites-le immédiatement plutôt que de le laisser traîner dans la boîte de réception.

Dossiers et règles automatiques​

  • Créez des dossiers pour classer les courriels par projet ou par type
  • Créez des règles pour classer automatiquement certains courriels récurrents (ex. : notifications automatiques d'un système)

Indicateurs de suivi (Flag)​

Marquez un courriel d'un drapeau pour le retrouver facilement dans votre liste de tâches — Outlook peut même créer une tâche automatiquement à partir d'un courriel signalé.

Les tâches Outlook​

Outlook comprend un module de tâches intégré au calendrier :

  • Créer une tâche à partir d'un courriel (glisser-déposer)
  • Définir une date d'échéance et un rappel
  • Synchronisation avec Microsoft To Do (voir section suivante)

Bonnes pratiques de nétiquette par courriel​

Rappel

Ces règles ont été présentées en détail dans la section communication et collaboration efficace.

  • Objet clair et précis
  • Message concis, structuré en puces si possible
  • Répondre à tous seulement si nécessaire (éviter de spammer toute une liste de distribution)
  • Utiliser CC pour informer, et non pour exiger une action
