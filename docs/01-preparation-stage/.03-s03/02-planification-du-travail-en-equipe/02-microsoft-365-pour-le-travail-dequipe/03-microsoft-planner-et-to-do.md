# ✅ Microsoft Planner et Microsoft To Do

Microsoft 365 propose deux outils complémentaires pour la gestion de tâches : **Planner** (gestion d'équipe) et **To Do** (gestion personnelle).

## Microsoft Planner

Planner est un outil de gestion de tâches **visuel** de type tableau **Kanban**, directement intégré à une équipe Teams.

### Concepts de base

| Concept       | Description                                                       |
| --------------- | ------------------------------------------------------------------- |
| **Plan**          | L'équivalent d'un projet ou d'un tableau de tâches                    |
| **Compartiment (bucket)** | Colonne du tableau (ex. : « À faire », « En cours », « Terminé »)     |
| **Tâche**         | Élément de travail assigné à une ou plusieurs personnes                |
| **Étiquette**     | Marqueur de couleur pour catégoriser (ex. : « Urgent », « Bug »)         |

### Une tâche Planner peut contenir

- Une **description** détaillée
- Une **date d'échéance**
- Des **personnes assignées**
- Une **liste de vérification** (checklist) de sous-étapes
- Des **pièces jointes**
- Un **niveau de priorité**

:::tip
Planner est excellent pour de **petites équipes** ou des projets simples. Pour des projets de développement logiciel plus complexes avec suivi Agile détaillé (sprints, story points, etc.), les équipes utilisent généralement un outil plus spécialisé comme **Jira** ou **Azure DevOps** (voir la section suivante).
:::

### Les vues de Planner

- **Tableau** — vue Kanban classique par compartiment
- **Graphiques** — visualise la progression (nombre de tâches terminées, en retard, etc.)
- **Planificateur** — vue calendrier des échéances
- **Mes tâches** — vue personnelle de toutes vos tâches assignées, peu importe le plan

## Microsoft To Do

**To Do** est l'outil personnel de gestion de tâches de Microsoft, pensé pour un usage individuel (contrairement à Planner qui est pensé pour une équipe).

### Fonctionnalités clés

- **Mes tâches assignées** : synchronise automatiquement les tâches qui vous sont assignées dans Planner et Outlook
- **Listes personnalisées** : créez vos propres listes (ex. : « Formation », « Idées », « Personnel »)
- **Ma journée** : liste spéciale où vous glissez chaque matin les tâches sur lesquelles vous voulez vous concentrer aujourd'hui
- **Rappels et récurrence** : pour les tâches répétitives

:::info Lien avec la planification personnelle
To Do est l'outil idéal pour appliquer concrètement les techniques vues précédemment : la fonctionnalité **« Ma journée »** s'applique très bien à la matrice d'Eisenhower ou à la méthode GTD.
:::

## Planner vs To Do — quel outil pour quel usage?

| Situation                                             | Outil recommandé |
| -------------------------------------------------------- | ------------------- |
| Suivre les tâches d'une équipe sur un projet                | **Planner**           |
| Gérer ma propre liste de tâches personnelles                 | **To Do**             |
| Voir en un coup d'œil tout ce qui m'est assigné (équipe + perso) | **To Do** (vue « Mes tâches assignées ») |

## En résumé

1. **Planner** = tableau Kanban d'équipe, simple et visuel, intégré à Teams
2. **To Do** = gestionnaire de tâches personnel, qui centralise aussi ce qui vous est assigné ailleurs
3. Ces outils sont un bon point d'entrée avant de passer à des outils Agile plus complets comme Jira, vus dans la prochaine section
