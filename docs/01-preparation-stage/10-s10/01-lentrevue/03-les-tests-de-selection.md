# 🧪 Les tests de sélection

Après vos entrevues, il est possible que l'entreprise vous demande de passer certains tests dans le cadre du processus de sélection.

:::note 💬 Pour démarrer
Avez-vous déjà fait un test de personnalité ou un test en ligne pour un emploi? Comment l'avez-vous vécu?
:::

## Les types de tests les plus communs

| Type de test                          | Description                                                                 |
| ------------------------------------------ | ---------------------------------------------------------------------------------- |
| **Tests psychométriques**                    | Évaluent des traits de personnalité, des préférences ou des comportements au travail  |
| **Test des couleurs**                        | Un type de test psychométrique basé sur les préférences de couleurs                    |
| **Tests de logique**                         | Évaluent le raisonnement logique et analytique                                         |
| **Tests techniques ou de connaissances**     | Évaluent vos compétences techniques concrètes (programmation, outils, etc.)              |
| **Mises en situation relationnelle**         | Évaluent votre comportement dans des interactions professionnelles simulées              |

:::tip Pour vous exercer
Vous pouvez essayer un exemple de [test de logique visuelle](https://test.psychologies.com/tests-qi/tests-psychotechniques/test-de-logique-visuelle) pour vous familiariser avec ce type d'évaluation avant une entrevue.
:::

### Les tests psychométriques

- **Répondez honnêtement et spontanément.** Ces tests contiennent souvent des questions répétées sous différentes formes pour détecter les incohérences
- Il n'y a pas de « bon profil » : l'employeur cherche à voir comment vous vous intégreriez à l'équipe

## Les tests techniques en détail

Les tests techniques sont particulièrement fréquents pour les postes en développement logiciel — attendez-vous à devoir démontrer vos compétences en programmation. Ils prennent généralement une de ces formes :

| Format | Description | Conseils |
| --- | --- | --- |
| **Questionnaire en ligne** | Choix multiples ou questions courtes (langage, SQL, Git, etc.) | Révisez les bases demandées dans l'offre |
| **Codage en direct** | Résoudre un problème devant un intervieweur | **Pensez à voix haute**, posez des questions de clarification |
| **Plateforme chronométrée** | HackerRank, Codility, etc. | Pratiquez sur ces plateformes avant |
| **Projet à la maison** | Petit projet à remettre en quelques jours | Code propre, README clair, respect du délai |

### Le codage en direct : la démarche compte plus que le résultat

1. **Reformulez** le problème pour vous assurer de l'avoir compris
2. **Posez des questions** sur les cas limites (liste vide? valeurs négatives?)
3. **Expliquez votre approche** avant de coder
4. Commencez par une solution **simple qui fonctionne**, puis améliorez-la
5. **Testez** votre code avec un exemple

:::warning Mises en garde
- **N'utilisez pas l'IA ou une solution copiée** si ce n'est pas permis : l'employeur pourrait vous demander d'expliquer votre code en entrevue, et ça se voit vite
- Pour un projet à la maison, **ne dépassez pas excessivement le temps demandé** — l'employeur veut voir ce que vous faites dans un cadre réaliste
- Lisez **toutes les consignes** avant de commencer
:::

:::note 💬 Question à la classe
Vous êtes en codage en direct et vous bloquez complètement. Vaut-il mieux rester silencieux et chercher, ou le dire à l'intervieweur? Pourquoi?
:::

## En résumé

1. Les tests de sélection s'ajoutent souvent aux entrevues, surtout pour des postes techniques
2. Ils peuvent évaluer votre **personnalité**, votre **logique**, ou vos **compétences techniques**
3. En test technique, montrez votre **démarche** : pensez à voix haute
4. Se familiariser à l'avance avec ces formats de test peut réduire le stress le jour venu
