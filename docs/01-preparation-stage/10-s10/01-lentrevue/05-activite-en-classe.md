# 🎭 Activité à faire en classe : simulation d'entrevue

## Objectif

Mettre en pratique la **méthode STAR**, votre **pitch de 60 secondes** et votre **non verbal** dans une entrevue simulée, puis recevoir une rétroaction constructive.

**Durée :** environ 50 minutes
**Format :** équipes de 3

## Préparation (10 minutes)

Individuellement :

1. Choisissez une **offre de stage réelle** qui vous intéresse (ou celle fournie par l'enseignant)
2. Préparez votre **pitch** (Présent → Passé → Futur)
3. Préparez **deux exemples STAR** tirés de vos projets ou expériences
4. Préparez **deux questions** à poser à l'employeur

## Déroulement (3 rondes de 10 minutes)

Chaque membre de l'équipe joue tour à tour les trois rôles :

| Rôle | Responsabilité |
| --- | --- |
| **Candidat** | Répond aux questions comme en vraie entrevue |
| **Intervieweur** | Pose 4 ou 5 questions de la banque ci-dessous, adaptées à l'offre |
| **Observateur** | Remplit la grille d'observation et chronomètre |

Après chaque entrevue, prenez **3 minutes** de rétroaction (observateur d'abord, puis intervieweur).

### Banque de questions pour l'intervieweur

1. Parlez-moi de vous.
2. Pourquoi ce stage vous intéresse-t-il?
3. Parlez-moi d'un projet dont vous êtes fier ou fière. Quel était votre rôle?
4. Parlez-moi d'une fois où vous avez eu un désaccord dans une équipe. Comment l'avez-vous réglé?
5. Parlez-moi d'une erreur que vous avez commise et de ce que vous en avez appris.
6. Quelle est votre plus grande faiblesse?
7. Une technologie de l'offre vous est inconnue. Comment vous y prendriez-vous pour l'apprendre?
8. Avez-vous des questions pour nous?

## Grille d'observation

| Critère | ✅ Fort | ⚠️ À améliorer | Commentaire |
| --- | --- | --- | --- |
| Pitch clair et en moins de 60 secondes | | | |
| Réponses structurées (STAR) avec un **résultat** | | | |
| Utilise « je » pour décrire ses actions | | | |
| Exemples concrets et en lien avec le poste | | | |
| Contact visuel et posture | | | |
| Débit et ton de voix | | | |
| Honnêteté face à une question difficile | | | |
| Questions pertinentes pour l'employeur | | | |

:::tip Donner une bonne rétroaction
Soyez **précis** et **bienveillants** : nommez une force, puis une piste d'amélioration concrète. « Ton exemple du projet Web était super clair, mais tu as oublié de dire le résultat » est beaucoup plus utile que « C'était correct ».
:::

## Retour en grand groupe (10 minutes)

:::note 💬 Questions de discussion
- Quelle question a été la plus difficile à répondre? Pourquoi?
- Qu'avez-vous remarqué en étant **intervieweur** que vous n'aviez jamais réalisé en tant que candidat?
- Quelle est **la** chose que vous changerez pour votre prochaine vraie entrevue?
:::
