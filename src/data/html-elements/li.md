### Item de liste (`<li>`)

Chaque élément d'une liste doit être contenu dans une balise `<li>` (list item).

<SandpackPlayground
  template="static"
  showTabs={false}
  files={{

  <ol>
    <li>Nyan Cat</li>
    <li>Grumpy Cat</li>
    <li>Lil Bub</li>
  </ol>
`
  }}
/>
